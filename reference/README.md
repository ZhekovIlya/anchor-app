# reference/

Source course material (Miro board exports and the course PDF). It is **not deployed** and nothing in `src/` or `data/` imports it.

- `miro/` — full board exports that used to sit in `public/theory/`.
- `pareja.pdf` — course PDF (was `scripts/pareja.pdf`).

To use a visual in a theory article, crop just the diagram or table you need from here and save the small crop into `public/theory/`. Keep crops small: everything in `public/` ships to every device.
